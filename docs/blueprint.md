# **App Name**: Spends

## Core Features:

- Expense Tracking: Manually input expenses or connect bank accounts to automatically track spending.
- Budget Creation: Set monthly budgets for different spending categories which includes onetime and recurring or subscriptions.
- Spending Categorization: Categorize expenses into predefined categories or create custom categories.
- Chart Visualization: Visualize spending patterns through charts (e.g., pie charts, bar graphs).
- Budget Goal Setting: Allow users to set financial goals and track progress.
- Bill & Subscription Reminders: Set up reminders for upcoming bills and recurring subscriptions.
- Intelligent Spending Insights: AI tool to analyze spending data and suggest potential savings.

## Style Guidelines:

- Primary color: Soft blue (#588A94) to create a sense of calm and trust.
- Background color: Very light blue (#F5F7FA) to ensure readability and a clean interface.
- Accent color: Muted purple (#F7CEDB) for interactive elements and key highlights, providing a subtle contrast.
- Body text: 'PT Sans', a sans-serif font for clean readability.
- Headline text: 'Space Grotesk', a sans-serif font, gives it a clean, modern touch.
- Use clean, minimalist icons for categories and actions.
- Prioritize a clean, intuitive layout with a focus on key insights.
- Subtle transitions and animations to provide feedback on user interactions.
